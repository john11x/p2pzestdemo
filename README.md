# p2pzestdemo

This repo contains the frontend app and the active backend implementation for the ZestP2P scheduling platform.

## Active backend

The current backend in use is the Spring Boot project in [springbackend](springbackend).

- Main app: [springbackend/src/main/java/zest/springbackend/SpringbackendApplication.java](springbackend/src/main/java/zest/springbackend/SpringbackendApplication.java)
- Backend package: [springbackend/src/main/java/zest/springbackend](springbackend/src/main/java/zest/springbackend)

## Frontend

The React + TypeScript frontend lives in [src](src).

## Repository layout

- [springbackend](springbackend) — active Java Spring Boot backend
- [src](src) — frontend application
- [docs](docs) — documentation and onboarding notes

## Repo hygiene

Generated files and local OS metadata are intentionally ignored or removed so the project stays cleaner and easier to navigate.
